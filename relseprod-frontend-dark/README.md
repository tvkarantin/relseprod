# ИИ-Рилс — frontend

Темная frontend-версия интерфейса продюсера рилсов по предоставленному дизайн-референсу.

Реализованы:
- экран конкурентов;
- библиотека рилсов с поиском и фильтрами;
- редактор сценария и вкладка аналитики;
- интерактивная навигация, моковые действия и адаптивная верстка;
- локальные изображения из предоставленного референса.

Backend и API пока не подключены — интерфейс работает на мок-данных и локальном состоянии.

## Запуск

```bash
npm run dev
```

Открой `http://localhost:4173`.

## Статическая сборка

```bash
npm run build
```

Результат появится в папке `dist/`.
